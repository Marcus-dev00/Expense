01.

Overview & Architecture

100% Offline-first local ledger

Expense is designed for privacy-conscious users in Malaysia. All records are stored exclusively in an embedded SQLite database on your device with exact integer sen precision.

Currency Standard: Amounts are stored internally as integer sen (`RM 124.50` = `12450` sen) to prevent floating-point errors.
01.

技术架构与隐私哲学

100% 本地嵌入式 SQLite 引擎

Expense 专为注重个人财务隐私的马来西亚用户设计。所有流水、分类、预算与账户配置全部保存在手机物理 SQLite 数据库中，零数据上报。

货币单位与存储精度： 底层全部采用整数分（sen）存储（例如 `RM 124.50` 存储为整数 `12450`），彻底消除浮点数计算误差。
01.

Arkitektur & Privasi

100% Lejar tempatan luar talian

Expense direka khas untuk pengguna di Malaysia. Semua rekod disimpan dalam pangkalan data SQLite peranti anda dengan ketepatan integer sen.

Standard Mata Wang: Nilai disimpan sebagai integer sen (`RM 124.50` = `12450` sen) untuk mengelakkan ralat pembundaran.

实时算术运算与 4.5 秒防误删撤销

06.

Accounts & Liabilities

Credit card liability sign inversion
Liability Accounting: For credit cards (`is_liability = 1`), expenses increase outstanding debt, while payments reduce it. `Net Assets = Asset Balances − Liability Balances`.
06.

多账户与信用卡负债

负债符号反转与净资产计算
信用卡负债记账： 信用卡标记为 `is_liability = 1`。发生支出时欠款增加，还款入账时欠款减少。净资产公式：`总资产（现金+银行） − 总负债（信用卡）`。
06.

Akaun & Liabiliti

Penyongsangan tanda liabiliti Kad Kredit
Perakaunan Liabiliti: Bagi kad kredit (`is_liability = 1`), perbelanjaan menambah hutang; bayaran balik mengurangkannya. `Aset Bersih = Jumlah Aset − Jumlah Liabiliti`.

独立应收账款与一键平账

OEM Autostart & Keep-Alive Guide

Brand-specific optimization checklist & lock app guide
XIAOMI / REDMI

HyperOS / MIUI

1. Settings → Apps → Manage Apps → Expense → Enable Autostart.
2. Battery Saver: Set to "No restrictions".
3. Recent Apps: Pull down Expense card and tap Lock icon 🔒.

SAMSUNG

One UI

1. Settings → Battery → Never sleeping apps → Add Expense.
2. Battery usage: Set to "Unrestricted".
3. Recent Apps: Tap Expense icon above card → "Lock this app" 🔒.

OPPO / ONEPLUS

ColorOS / OxygenOS

1. Settings → Apps → Auto-launch → Enable Expense.
2. Battery: Allow background activity.
3. Recent Apps: Tap three dots (⋮) on card → "Lock" 🔒.

VIVO / IQOO

OriginOS / FuntouchOS

1. Settings / iManager → Autostart → Enable Expense.
2. Background power: Allow high background consumption.
3. Recent Apps: Slide down Expense card → "Lock" 🔒.

Why Lock the App in Recent Tasks (🔒)?
Returning to the home screen or locking the screen never terminates the notification listener. However, tapping "Clear All" (the broom / trash button) in the app switcher force-stops apps. Locking the card exempts Expense from "Clear All" permanently (only needs to be performed once).

主流机型后台保活配置

小米/三星/OPPO/vivo 指南与多任务加锁
小米 / REDMI

HyperOS / MIUI

1. 系统设置 → 应用管理 → Expense → 开启「自启动」。
2. 省电策略：设为「无限制」。
3. 多任务加锁：呼出多任务后台，下拉 Expense 卡片点击【小锁头 🔒】锁定。

三星 (SAMSUNG)

One UI

1. 系统设置 → 电池 → 应用程序耗电管理 → 添加至「永不休眠应用」。
2. 电池优化：设为「无限制」。
3. 多任务加锁：点击卡片上方图标选择「锁定此应用程序 🔒」。

OPPO / 一加

ColorOS

1. 系统设置 → 应用管理 → 应用自启动 → 勾选 Expense。
2. 电池策略：开启「允许完全后台行为」。
3. 多任务加锁：点击卡片右上角菜单【⋮】选择「锁定 🔒」。

VIVO / IQOO

OriginOS

1. i 管家/系统设置 → 开启「后台自启动」。
2. 电池管理：允许「高耗电后台运行」。
3. 多任务加锁：在多任务后台下滑 Expense 卡片点击「加锁 🔒」。

为什么要给多任务卡片加锁（🔒）？
日常返回桌面、锁屏待机绝不会导致服务断连。但国内厂商在点击多任务底部的【一键清理/小扫把】时会强杀未锁定的应用。在多任务界面给 Expense 加锁后，一键清理将永久跳过它，操作一次终身生效，彻底杜绝漏单！
